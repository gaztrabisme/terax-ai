# UAT: k5
Design: docs/design.md sections 6.3 (K0 baseline) and 6.5 (K5.3); principles served: 10 (measured, then built), 1 (the disk is the truth)
Required units: none
Fixture variant: clean (section 6.2 fixture project and zsh fixture; the K0 baseline rows re-expressed with canonical ids)
Platform/shell: macOS; integrated zsh fixture
Target phase: current
Row deadline: 90 per row (a deadline bounds a stuck test, it is not a latency claim)

1. Given the fixture project that this run has not opened before
   When I launch the installed app on the project with the `--pi` argument
   Then the window opens on the project and `<project>/.pi/launcher.log` holds the prepare steps with no FAIL line
   Shot: 01-launch.png; Evidence: the launcher log path with its step list
2. Given the app open on the project
   When I read the window title and resolve the active tab radio [uat:tab-active]
   Then the title is "Terax" (it does not carry the tab name) and the radio's accessibility name is `<tab title> Close tab`
   Shot: 02-title.png
3. Given the chat tab active
   When I click [uat:settings-button] (`Settings`)
   Then the Settings panel shows the pi binary, the agent, the agent dir and a provider row; close Settings afterwards
   Shot: 03-settings.png
4. Given the chat tab active with no turn yet
   When I type "List the files in this folder in one line" into [uat:composer-input] (`pi composer`) and press Enter
   Then a user block [uat:turn-user] appears, then an answer block [uat:answer-body] with an activity fold [uat:turn-fold] and a footer [uat:usage-footer] beginning `generation`
   Shot: 04-turn.png
5. Given the completed tool-bearing turn
   When I click [uat:turn-fold] (text beginning `generation`)
   Then the tool rows [uat:tool-row] expand under it with real tool names and completion marks
   Shot: 05-fold.png
6. Given the session from row 4
   When I click [uat:sessions-button] (`Sessions`) and resolve [uat:sessions-popover], then type a fragment of the row 4 prompt into [uat:sessions-search] (`Search pi sessions`) and click the matching [uat:session-row] hit for a past session
   Then the active session switches to that saved session and the transcript scrolls to its exact prompt; switch back to the current session
   Shot: 06-sessions-recovery.png
7. Given the Sessions view closed
   When I click [uat:board-button] (`Board`) and resolve [uat:board-panel], then click one [uat:board-ticket] card
   Then the columns render with the seeded tickets and [uat:ticket-sheet] opens with the ticket workpad heading; press Escape to close the sheet with no verb confirmed
   Shot: 07-board-sheet.png
8. Given the chat composer with an empty draft
   When I click [uat:attach-images] (`Attach images`), choose the fixture's `sample-a.png` and send "describe the attached image in five words"
   Then the user block carries [uat:attachment-chip] and `<project>/.pi/attachments/` holds the saved image file
   Shot: 08-attachment.png; Evidence: the saved attachment file path
9. Given a new terminal tab with the composer off by default
   When I run "echo uat-baseline" and then "false" in [uat:terminal-emulator]
   Then one [uat:terminal-block] carries the echoed text with the green dot of [uat:exit-dot-ok] and a second block carries the red dot of [uat:exit-dot-fail]
   Shot: 09-terminal-blocks.png
10. Given the answer block from row 4
    When I click [uat:open-in-editor] (visible `Open in editor`) in [uat:answer-actions]
    Then a nonempty Markdown file appears under `<project>/.pi/answers/`
    Shot: 10-open-in-editor.png; Evidence: the created answers file path

Break attempts (notes only, each with a shot or log line): send an empty prompt and confirm nothing is submitted; send a second prompt while the first is still streaming and confirm the visible refusal or `Stop` state; press Escape during a turn and confirm the turn state is unchanged; resize the window to 900 px wide and confirm the transcript, strip and composer stay usable with rects re-read.
